# 2015年图表隔日振荡的诊断与修正

## 结论
问题主要来自旧算法在低库容边界的显式日步长，不是已识别的原始入流隔日归零。原算法在日初库容90TAF时，因配置曲线C(90)=0而全天不放水；入流把库容抬高后，次日又集中放水并回到90TAF，形成数值伪影。只检查水量守恒不能排除它。

## 数据与因果核对
- 官方原始入流、蒸发文件保持不变，来源哈希仍可核对。
- 2015-06-20入流1.574876 TAF，旧算法下泄为0，新算法下泄约1.566867 TAF。
- 同一输入、同一策略和参数，仅调整出库能力更新步长；2015-06-15至09-30，A的零下泄天数由54降至0。
- 没有删除原始洪峰，也没有移动平均或对绘图曲线做平滑。

## 数值解释
90-100TAF区间出库能力斜率为3500cfs/TAF，换算后约6.94/天。局部显式迭代因子1-6.94*dt在dt=1天时约-5.94；边界裁切使失稳表现为隔日振荡。dt=1/24天时约0.71。

## 修正
每天24个内部子步，日入流、蒸发和目标在日内均匀分配，随子步库容更新能力后逐步守恒。子步是数值积分，不是观测小时资料；实际小时洪峰不能由其推定。

## 收敛与结果变更
每日1、4、12、24、48、96子步结果见results/research/timestep_convergence.csv。2015年三策略24与96子步体积满足率差均小于1e-6、缺水平方差小于1e-5。该证据覆盖此低库容案例，不能冒充全部真实水力过程验证。

所有基准、训练、压力情景与报告统计均已重算。原12.33%的缺水平方改善值失效，修正版约10.31%。旧版研究输出仅在本地archive/pre_numerical_fix中留作审计，不上传为当前结果。正式图保留修正后的逐日输出，并附before/after诊断图figures/research/08_numerical_correction.png。
