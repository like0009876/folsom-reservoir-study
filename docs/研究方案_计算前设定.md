# 计算前研究设定
研究定位：真实官方水文输入下的简化管理情景试验，非真实调度复现。
训练水文年：2000、2003、2007；独立检验：2011、2012、2015、2016。
入选条件：完整水文年；官方入流与计算蒸发有限非负、来源标记为空、OBS DATE无跨日差异。其他字段缺测不补；它们不作为本试验的外生驱动。各年独立初始库容466.1TAF，不串接不相邻年份。
物理边界：库容975TAF、保留库容90TAF，按项目库容—泄量曲线控制出库；能力不足时记录防洪控制曲线超出和非控制溢流，不强制伪造可行性。蒸发纳入水量平衡。
运行约束：采用公开项目简化固定季节曲线，400TAF冬季控制库容；实际官方控制库容仅作2011年敏感性替换和背景核对，不用历史观测库容放宽约束。
需水：原曲线前365项按月日映射；2月29日取2月28日和3月1日均值。它是总有益下泄目标，不是实测消耗用水。供水指标均指该目标的下泄满足程度。
生态代理：采用手册所述D-893历史250/500cfs季节低流量线作为最低下泄筛查代理，不声称Folsom单库下泄等于Nimbus河段达标；不与总需水重复扣水。另比较零/双倍该代理的敏感性。
三策略：A按需求供水；B库容比例低于0.5时目标压减至60%；C连续两参数限水规则网格搜索。全部共享同一防洪与物理约束。
优化目标：训练年份原入流及80%入流情景的平均日相对缺水平方，加0.05倍年末低于300TAF的归一化储备缺口平方。权重、300TAF储备线均为管理偏好，不是经济价值或法律标准。
C参数候选：启动阈值0.2、0.35、0.5、0.65、0.8、1.0；最低供给比例0.1、0.25、0.4、0.55、0.7、0.85、1.0。无未来入流信息；当日入流视为日内可得，同一信息条件用于全部策略。
指标：有益下泄体积满足率、完全满足天数比例、缺水平方、最大日缺水比例、连续缺水长度、恢复率、年末库容、控制曲线超出、下泄超过简化安全上限、生态代理满足率；社会公平仅讨论假设性基本用水保障和限水负担，不能推断真实群体分配。
敏感性：入流缩放、需水缩放、初始库容、控制曲线上移、库容上限、生态代理和优化偏好；测试集参数保持冻结。另用连续1243天官方入流蒸发记录检验跨年携带效应，不插补、不把该重叠样本称为独立验证。
交付：可复现脚本、输入清单、逐日结果、汇总表、敏感性分析、图表、研究报告和验证记录。不得挑选性省略劣势结果。
